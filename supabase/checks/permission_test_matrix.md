# 여행 권한 테스트

| 계정 | 여행 목록 | 일정/장소/경비 조회 | 편집 | 멤버 관리 | 여행 삭제 |
|---|---:|---:|---:|---:|---:|
| 소유자 | 가능 | 가능 | 가능 | 가능 | 가능 |
| 편집자 | 가능 | 가능 | 가능 | 불가 | 불가 |
| 보기 전용 | 가능 | 가능 | 불가 | 불가 | 불가 |
| 비멤버 | 표시 안 됨 | 불가 | 불가 | 불가 | 불가 |

## 실제 테스트 순서

1. 소유자 계정으로 여행을 만든다.
2. 두 번째 계정을 편집자로 초대한다.
3. 두 번째 계정에서 일정 하나를 만들고 수정한다.
4. 소유자가 두 번째 계정을 보기 전용으로 변경한다.
5. 두 번째 계정에서 추가·수정 버튼이 숨겨지고 직접 요청도 거부되는지 확인한다.
6. 초대되지 않은 세 번째 계정에서 여행이 목록에 나타나지 않는지 확인한다.
7. 편집자가 `owner_id`와 owner 역할을 변경할 수 없는지 확인한다.
